# Sonic Recharged #35 — programme interactif

Mini-site autonome (un seul fichier `index.html`) pour les 5 salles du samedi 7 novembre 2026 à Wolfwil.

## Fonctionnalités
- Programme des 5 salles (42 DJ/sets) avec heures officielles des affiches
- Vue chronologique et sélecteur horaire
- Favoris conservés sur chaque appareil via `localStorage`
- Export texte des favoris, partage natif sur smartphone
- Responsive, sans compte, sans backend et sans dépendance externe

## Publication sur GitHub Pages
1. Créer un dépôt **public** `sonic-2026` sur GitHub.
2. Dans **Add file → Upload files**, téléverser `index.html` (et `README.md` facultatif), puis valider.
3. Dans **Settings → Pages**, choisir `Deploy from a branch`, branche `main`, répertoire `/ (root)` et enregistrer.
4. L'adresse sera `https://VOTRE-PSEUDO.github.io/sonic-2026/` (après publication effective).

## Remarques
Les fins des derniers sets sont annoncées `END` sans horaire précis : la vue chronologique affiche ces sets jusqu'à 05:30 à titre indicatif. Les favoris sont propres à chaque navigateur et ne se synchronisent pas entre appareils. Site non officiel réalisé à partir des cinq affiches fournies.
